# Group 6 - Project 3: Tesla-Style 3D Driving Visualization

## Overview

This project builds a Tesla-style 3D driving visualization from dashcam video.
The pipeline detects objects (vehicles, pedestrians, traffic lights, signs, cones),
estimates depth and 3D orientation, classifies vehicle types, detects brake lights
and turn signals, detects lane markings, and renders everything in Blender as a
3D scene.

## Requirements


### External models (not included due to size)

These must be downloaded separately and placed in the expected paths:

- **YOLO11m** — `yolo11m.pt` (auto-downloads via ultralytics)
- **YOLO11m-cls** — `yolo11m-cls.pt` (ImageNet vehicle classification)
- **YOLOv8s-World** — `yolov8s-worldv2.pt` (speed sign candidate detection)
- **FCOS3D** — `models/fcos3d/fcos3d_r101_finetune.pth`
- **Video-Depth-Anything-Large** — `~/metric_video_depth_anything_vitl.pth`
- **RTMPose3D** — `models/mmpose/checkpoints/rtmdet_m_person.pth` and `rtmw3d-l_cocktail14.pth`
- **Detic** — Installed separately (set `DETIC_DIR` env var to its path)
- **RAFT** — `RAFT/models/raft-things.pth` (motion classification)
- **CLRerNet** — `CLRerNet/work_dirs/clrernet/clrernet_culane_dla34_ema.pth`
- **EasyOCR** — `pip install easyocr` (speed sign text reading)
- **Blender**  — must be on PATH
- **base_scene.blend** — Blender scene file at project root (generated by `setup_scene.py`)

### Data

Place the provided `P3Data/` directory at the project root:

```
P3Data/
  Sequences/scene1..scene13/Undist/   (undistorted front camera videos)
  Calib/calibration_results.json      (camera intrinsics)
  Calib/extrinsics.json               (camera extrinsics) [not used but breaks the code if removed]
  Assets/                             (Blender 3D models)
```

### Path configuration

Some scripts have hardcoded paths that need adjusting for your machine:

- `detect_objects.py` / `detect_brake_lights_detic.py` — `DETIC_DIR` (set via env var or edit default)
- `estimate_depth.py` — `CHECKPOINT` path to depth model weights
- `motion_classify.py` — `scene_dir` and `det_json` paths in `__main__`
- `fcos3d_infer.py` — `MM3D_PKG` path to mmdet3d package
- `run_all_detections.sh` — `PY_BASE` and `PY_MM3D` python interpreter paths

## Pipeline Run Order

All commands run from the project root directory.

### Phase 1: Detection + Depth

```bash
# Step 1: YOLO detection with ByteTrack tracking (front camera, all frames)
conda activate dr
python detect.py --scene scene1 --sample_rate 1

# Step 2: Metric depth estimation
python estimate_depth.py --scene scene1 --sample_rate 10

# Step 3: Lane detection (requires clrernet env)
conda activate clrernet
export PYTHONPATH=$PYTHONPATH:$(pwd)/CLRerNet:$(pwd)/CLRerNet/libs/models/layers/nms/src
python add_lanes.py --scene scene1
```

### Phase 2: 3D Estimation + Classification

```bash
# Step 4: FCOS3D monocular 3D detection (yaw, depth, dimensions)
conda activate mm3d
python fcos3d_infer.py --scenes scene1

# Step 5: Detic additional objects (cones, poles, dustbins)
conda activate dr
python detect_objects.py --scenes scene1

# Step 6: Vehicle sub-classification (YOLO11-cls ImageNet)
python classify_vehicles_imagenet.py --scenes scene1
python merge_imagenet_into_detections.py scene1

# Step 7: Heading estimation (copies FCOS3D yaw + per-track smoothing)
python estimate_heading.py --scenes scene1

# Step 8: Pedestrian 3D pose (RTMPose3D)
conda activate mm3d
python estimate_pose.py --scenes scene1
```

### Phase 3: Brake Lights + Motion + Rendering

```bash
conda activate dr

# Step 9: Brake light detection (Detic-based)
python detect_brake_lights_detic.py --scene scene1

# Step 10: Post-process brake signals (v7 strategy)
python postprocess_brake_strategies.py --scene scene1

# Step 11: Motion classification (parked vs moving, RAFT optical flow)
python motion_classify.py --scene scene1

# Step 12: Blender rendering
blender --background --python render_blender.py -- --scene scene1
```

### Output videos

After rendering, generate videos from the rendered frames:

```bash
# single scene
ffmpeg -framerate 24 -pattern_type glob -i "renders/scene1/render_*.png" \
    -c:v libx264 -pix_fmt yuv420p Videos/OutputVisualizationVideoSeq1.mp4

# all 13 scenes
for i in $(seq 1 13); do
    ffmpeg -framerate 24 -pattern_type glob \
        -i "renders/scene${i}/render_*.png" \
        -c:v libx264 -pix_fmt yuv420p \
        Videos/OutputVisualizationVideoSeq${i}.mp4
done
```
